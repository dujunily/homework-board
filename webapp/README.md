# 作业板 · 电脑端录入页

一个单文件网页，用来在电脑上批量布置作业。写完直接落到坚果云同步文件夹，坚果云客户端负责上传，电视端自动拉取。

- **不联网**：页面只写本地文件，不请求任何接口，不碰账号密码
- **不用装 App**：一个 `index.html` + 一个本地静态服务，Windows / macOS / Linux 都能跑
- **浏览器要求**：Chrome 或 Edge（Safari、Firefox 不支持文件夹写入）

<br>

## 怎么启动

双击对应系统的入口即可，三个平台逻辑完全一样：起一个只监听 `127.0.0.1` 的静态服务，然后自动打开浏览器。

| 系统 | 双击这个 | 实际做了什么 |
|---|---|---|
| Windows | `启动-网页版.bat` | 有 Python 就用 `py -3 serve.py`；没有就用 PowerShell 版服务（`serve.ps1`，不装任何东西） |
| macOS | `启动-网页版.command` | `start.sh` → `python3 serve.py` |
| Linux | `start.sh` | 同上 |

> macOS 首次双击若提示「无法打开，因为来自身份不明的开发者」：右键 → 打开 → 再点一次「打开」。
>
> 命令行也行：
>
> ```bash
> python3 serve.py            # 自动挑空端口（8123 起）并开浏览器
> python3 serve.py 8123       # 指定端口
> python3 serve.py --no-open  # 只起服务
> ```

关掉那个终端窗口即停止服务，录入过程中别关。

**为什么不能直接双击 `index.html`**：Chrome / Edge 在 `file://` 下不把页面当安全上下文，
「选择文件夹」拿不到写入授权，页面存不了东西。走 `http://127.0.0.1` 才可以。

<br>

## 怎么用

1. 点「选择文件夹」，选中坚果云同步文件夹里的 **`作业板`** 目录
   - 只需选一次，之后自动记住（存在浏览器 IndexedDB）
2. 选科目 → 打标题 → 补充说明 → 加图 → 点「保存并同步」
3. 点右上角的 `‹` `›` 切前一天/后一天（电脑端是唯一允许改日期的端，适合周末把一周排好），
   不是今天时会出现「回到今天」
4. 保存成功后页面会调一下本地服务的 `/ping`，本机替它往局域网喊一嗓子（UDP 47823，
   和手机端同一套暗号），电视 1~2 秒内就更新——不用去动电视遥控器

图片支持 **⌘V / Ctrl+V 直接粘贴截图**，也可以一次拖入多张。

<br>

## 为什么它比手机 App 更适合在电脑上用

| | 电脑网页 | 手机 App |
|---|---|---|
| 网络 | **完全不联网**，写本地文件 | 需要 PUT 到坚果云 |
| 账号 | 不需要账号密码 | 需要应用专用密码 |
| 图片 | ⌘V 粘贴截图、一次拖多张 | 拍照或相册 |
| 批量 | 一屏连写五条，周末把一周排好 | 一条一条来 |
| 依赖 | 无（不引 CDN、不引字体库） | 需安装 |

<br>

## 写入规则（与手机 App 一致）

```
图片 → img/YYYY-MM-DD/<8位hex>.jpg     （长边压到 1600px，JPEG q=0.8）
     → day/YYYY-MM-DD.json             （先读，按 id 合并，再写回）
     → manifest.json                   （回写该日的 itemCount）
     → POST /ping                      （本机广播，让电视立刻来拉）
```

> **浏览器发不了 UDP 广播**，所以「通知电视」这一步由 `serve.py` / `serve.ps1` 代劳：
> 页面只发一个 `POST /ping`，服务端用 `HOMEWORK-BOARD/SYNC/1` 这个暗号往
> `192.168.x.255` 和 `255.255.255.255` 的 47823 端口连发 3 次，6 秒后再补发一轮
> （等坚果云把文件传上去）。喊不出去也不影响保存，最坏退回「切回前台才更新」。

- **先读后合并**：不会覆盖别处写入的条目
- **未知字段原样保留**：不破坏数据契约，手机端加的字段不会被网页吃掉
- **`fileEtag` 写空串**：本地写拿不到服务端 ETag，电视端对这天降级为「每次都下载 json」（文件很小，无感）
- **写完回读校验**：重新读一次 day json，条数对不上或刚写的那条不在文件里就直接报错，不会静默显示「已保存」
- 图片文件名随机生成且**永不复用**；删除条目时图片保留不删（无引用，电视端不显示，不影响使用）

## 自测

不需要浏览器，也不需要起服务：

```bash
node test-logic.js
```

它把 `index.html` 里的脚本抽出来，配一套假 DOM + 落在系统临时目录的假目录句柄，
真的跑 `save()` / `switchDate()` / `setValidUntil()`，检查 30 条断言——
包括「不覆盖手机端写入的条目」「编辑不产生重复」「order 连续」
「manifest 的 itemCount / fileEtag 正确」「图片路径合规且不塞进 json」「切日期不影响今天」
「周五周六默认管到周日」。

## 注意

- **坚果云客户端必须开着**。网页只写本地磁盘，上传是坚果云客户端干的；客户端没运行，
  文件就只是躺在本机，云端和电视永远看不到（这种「以为保存了其实没上云」最难查，先看菜单栏有没有坚果云图标）。
- **同一天不要在手机 App 和网页同时编辑**。两边都是「读-改-写」，几乎同时保存时后写的一方会覆盖前一方。隔开几十秒就没问题。
- 提示「写入失败」多半是坚果云客户端正在同步/占用该文件，等几秒重试。
- 目录里的 `.DS_Store`、坚果云的冲突副本（`xxx 的冲突副本.json`）与本应用无关，但会让目录变乱，可以定期清。
- 图片总量会持续增长。电视端有 200MB 缓存上限，云端目录建议每季度清一次超过 60 天的 `img/` 子目录。
